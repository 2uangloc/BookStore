# 📚 Book Store MVC (.NET 9)

Website bán sách online được xây dựng bằng ASP.NET Core MVC.

## ✅ Tính năng

- 🛒 Mua sách, giỏ hàng, thanh toán Stripe, Momo, COD, Bank
- 👤 Đăng nhập, phân quyền Admin - Employee - Customer
- 🔐 Ghi log hoạt động Create/Update/Delete (Audit Log)
- 📦 Quản lý đơn hàng, trạng thái xử lý, thanh toán
- 📊 Quản lý dữ liệu bằng DataTables (AJAX, lọc)

## 🛠️ Công nghệ

- ASP.NET Core MVC + Entity Framework Core + Identity
- Stripe API, Momo Redirect API
- Bootstrap 5, SweetAlert2, Toastr, jQuery DataTables
